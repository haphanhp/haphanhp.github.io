Stack

The tools I use to build, publish and keep my garden growing.

🤖 Coding agents

Claude Code The strategist: it thinks about the big picture and plans the next move while I nod wisely.
Cline The muscle-bound builder inside VS Code: hunts through folders, edits files and tidies up the mess while I supervise.
Cursor Still on a first date with it, mostly to see if it keeps a project's context tidy.

🚦 AI routing

9Router One endpoint that keeps Cline running on many models, completely free, so I get more done without watching the meter.

🖥️ Editors & terminal

VS Code Where I edit code and config files.

🧩 Languages & frameworks

Astro Builds the pages of this site from Markdown files, one small page at a time.

📚 Notes & knowledge

Obsidian Home of my vault: thousands of notes, tagged, linked and only slightly overgrown.
Quartz Turns part of the vault into 2ndbrain, so my second brain gets a front door.
Eleventy Waters the Digital Garden: plain files go in, tidy pages come out.

⚙️ Automation

n8n Self-hosted on a VPS with Docker, quietly doing the chores while I pretend to be productive.
Google Cloud The cloud I visit when my laptop needs a break.
🖥️ VM A small always-on machine that keeps the workflows awake.
ClickUp Where my tasks live; n8n keeps it in sync so I do not have to copy things by hand.

🔐 Networking & security

Tailscale Digs a private tunnel so my Obsidian plugin can talk straight to n8n on the VPS, no public doors left ajar.
Bitwarden Keeps my everyday passwords, so my brain can stay busy with more important things, like noodles.
KeePassXC The offline backup vault for client IDs, API tokens, PATs and other secrets.

🚚 Hosting & delivery

Vercel Ships my small apps with one push and no ceremony.
Netlify Ships the projects dashboard and its little functions, so the heatmap can bloom.
GitHub Pages Hosts this site, a no-fuss home for pages that just want to exist.
Namecheap Where I bought haphan.digital, the address of the whole garden.

🗄️ Data & storage

Supabase My pick for the backend when a small app needs a database.

🎨 Design & content

Lovable Where I sketch a first version of an interface before refining it.

🛠️ Tools I built

Nói ra chữ Dictate Vietnamese and paste the text anywhere.
📈 Project dashboard Turns my project notes into progress bars and an activity heatmap.
